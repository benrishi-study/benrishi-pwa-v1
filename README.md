# 弁理士ミニテスト PWA v1

iPad横画面を主役にした、弁理士試験用の○×学習PWAです。MacBookでも同じUIで使えます。

## 入っている機能
- 「今日の10問」：D 4 / C 2 / B 1 / A 1 / NEW 2 を目安に自動選択
- iPad横画面の左右2カラム（左＝問題、右＝解説）
- ○×回答と即時解説
- 苦手復習（Dだけ / C・D / 最近の誤答）
- 分野別演習
- 成績（回答数・正答率・A/D件数・分野別集計）
- Excel（.xlsx/.xls）から問題を追加・更新
- 学習履歴を端末内（localStorage）に保存
- 問題IDが同じならExcel更新後も学習履歴を引き継ぎ
- PWA対応・オフラインキャッシュ

## まずMacBookで確認する
`index.html`をダブルクリックしても基本機能は動きます。
PWA・オフライン機能まで確認する場合は、このフォルダをローカルWebサーバーで配信してください。
例：ターミナルでこのフォルダに移動し、`python3 -m http.server 8765` を実行 → `http://localhost:8765` を開きます。

## iPadでPWAとして使う
PWAのインストールにはHTTPS配信が必要です。
このフォルダ一式を静的Webホスティング（GitHub Pages / Cloudflare Pages / Netlify等）に置き、iPadのSafariでそのURLを開きます。
その後、Safariの共有メニューから「ホーム画面に追加」を選びます。

## Excelの列名
次の列を読みます。
- 問題ID（必須）
- 分野
- 単元
- 論点
- 問題文（必須）
- 正解（○ または ×、必須）
- 解説
- 条文

シート名は「ミニテスト試作20問」を優先し、なければ「問題データ」、それもなければ先頭シートを読みます。

## データについて
初期状態では、今回作成したミニテスト試作20問を内蔵しています。
同梱の `sample-data.xlsx` を使ってExcel読込を試せます。

## 現在の保存方式
学習履歴は各端末内だけに保存されます。iPadとMacBookの同期はv2候補です。
